# Visual contract
- Canvas: 2000 × 960, white, full-width landscape overview.
- Font: Arial, figure title 38px, stage headings 29px, core labels 24–28px, annotations 22–23px.
- Main arrows: dark #263238, 1.8px; snapshot/parameter control: gray #6B7280, dashed. Actual traffic visitation: green.
- Semantic palette: input #E8F2F5/#58727D; shared standard policy/continuation #EAF0F6/#63758A; paired comparison #F1D7D4/#B44948; scoring/update #F4EEDC/#9A7B3F; action/visitation #E5F1E3/#5A8A55.
- Rounded cards: 12px; standard stroke 1.7px; contribution stroke 2.3px.
- Outer whitespace: 18px minimum at left loop, otherwise 40–52px. Horizontal flow has one detailed training-only container.
- Network dots and legend dots encode junctions/categories, not decorative token blocks.
- All important computation is native editable geometry; no external artwork or logos.
- Paper-scale check: a 1000px-wide raster is reviewed for hierarchy. Small default/legend text is secondary; core paired context and stages must remain readable.

Final typography: math indices use editable HTML sub/sup with ordinary Arial glyphs; unsupported Unicode subscript characters were removed. Snapshot control uses y=180; parameter feedback uses y=830; legend uses y=902..938.
